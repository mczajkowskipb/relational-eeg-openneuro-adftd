# Feature definitions

P0 contains amplitude-decile features: RAW_DECILES, DERIVED_DECILES_ALL, REGION_AGGREGATES_ALL.

P1 contains PSD/bandpower features: PSD_ABSOLUTE_CHANNEL_BAND and PSD_REGION_ABSOLUTE.

The main paper path starts from public derivative EEGLAB `.set` files. Raw EEG preprocessing is not presented as the central contribution.
